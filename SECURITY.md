# Security policy

We take the security of Pitch Mentor and its API clients seriously. Thank you for helping keep our users safe.

## Reporting a vulnerability

**Please do not open a public GitHub issue, discussion or pull request for security problems.**

Report privately by either:

- emailing **support@pitchmentor.net** with the subject line `SECURITY:` followed by a short title, or
- using GitHub's **[Report a vulnerability](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)**
  button on the affected repository's *Security* tab.

If you can't use either, message a moderator on [Discord](https://discord.gg/SkcxVEJ6wQ) asking for a private
channel. Don't post details in public channels.

Please include:

- the affected repository, package and version (or the API endpoint / page on pitchmentor.net),
- steps to reproduce or a proof of concept,
- the impact you expect, and
- how you'd like to be credited, if at all.

## What to expect

- We acknowledge your report within **3 business days**.
- We keep you updated while we investigate and tell you when a fix is released.
- We credit reporters in the release notes or advisory unless you prefer to stay anonymous.

## Scope

In scope: the clients in this organization (`pitchmentor-node`, `pitchmentor-python`, `pitchmentor-go`,
`pitchmentor-cli`, `pitchmentor-mcp`), the Pitch Mentor API (`api.pitchmentor.net`), and `pitchmentor.net`.

Please don't run denial-of-service tests, social-engineer our team or users, or access data that isn't yours.
Use your own account and team for testing. Good-faith research that follows this policy is welcome, and we won't take
legal action against it.

## Supported versions

Security fixes are released for the latest minor version of each client. Upgrade to the latest release to receive them.
