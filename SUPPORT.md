# Getting help

| You want to… | Go to |
|---|---|
| Ask a question, share an idea, or talk to the team | [Discord](https://discord.gg/SkcxVEJ6wQ) |
| Read the API reference and guides | [pitchmentor.net/docs](https://pitchmentor.net/docs) |
| Check whether the API is up | [pitchmentor.net/status](https://pitchmentor.net/status) |
| Report a bug in an SDK, the CLI or the MCP server | an issue in that repository |
| Get help with your account or billing | [pitchmentor.net/help](https://pitchmentor.net/help) or support@pitchmentor.net |
| Report a security vulnerability | our [security policy](SECURITY.md) (privately, please) |

When asking about a client, include the package name and version, your language runtime version, and the status, code
and message of the failing call. Never paste your API key.
